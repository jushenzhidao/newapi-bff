# 0.115.* 声明了 starlette<0.47.0，会把 starlette 锁在有漏洞的版本上；
# 0.141 起放开为 starlette>=0.46.0（无上界），才能装下修复版。
# FastAPI 自身无已知漏洞，升级它是为了解开下面 starlette 的版本上限。
fastapi==0.141.1

# 必须显式声明：fastapi 只要求 starlette>=0.46.0，装 fastapi 不会自动升 starlette，

# 1.6.0 覆盖全部 7 条告警，其中真实可利用的是 /static/* 的 Range 头 O(n^2) DoS
# —— app/main.py 挂了 StaticFiles，该路径对外可达。
# 详见 SECURITY-DEPS.md。
starlette==1.6.0

uvicorn[standard]==0.30.*
httpx==0.27.*

# 会话 Cookie 的 AES-256-GCM 加解密（app/security.py）。
# 已移除 itsdangerous：它只签名不加密，载荷是 base64 明文 JSON，而会话里装着
# 用户的 new-api PAT —— 任何读到 Cookie 字符串的人无需密钥即可直接解出。
# 钉死小版本：加密是安全边界，不接受 * 通配带来的意外升级。
#
# 43.0.3 有 6 条告警。本项目只用 AESGCM+HKDF 对称加密，不做证书链校验，
# 故 5 条 X.509 相关的不可达；真正需要修的是 wheel 内置 OpenSSL 漏洞
# （GHSA-537c，httpx 出站 TLS 依赖它）。
cryptography==50.0.1
